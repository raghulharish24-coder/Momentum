
## ✨ Features

- *Chat-based habit tracking* — type things like add habit reading or done reading and the bot handles it
- *Daily schedule manager* — add and view your day's plan through chat
- *Streak tracking* — stay motivated by watching your consistency grow
- *Clean, modern dashboard* — dark UI designed to feel good to open every day
- *Firebase-powered* — your data persists across sessions (coming in Phase 4)

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript (vanilla)
- Firebase (Firestore + Auth)
- Hosted on GitHub Pages
